NYC Who's On First Counties

Knowledge resource

A governed public view of Who's On First as a boundary-data publisher — the five exact current county gazetteer records used by NYC Boundaries. For how these records compare against DCP, the Census Bureau, OpenStreetMap, and other independently governed sources, see NYC Boundaries.

Dataset

This page governs five county records from the whosonfirst-data-admin-us repository, pinned at commit c4e4f9b. A sixth record — the New York locality (WOF ID 85977539) — supplies five-county hierarchy context but is not counted as a boundary assertion; it is not represented in the measurements table below.

Validation and provenance

Each record's identity, Census GEOID/HASC concordance, and source-owned wof:lastmodified value were retrieved directly from the pinned repository commit and cross-checked against the governed assertion records via exact git blob SHA; this page does not independently verify the underlying Quattroshapes geometry. For independent cross-source verification of these records, see NYC Boundaries.

Limitations

The five governed records are the exact versions retrieved at the pinned commit c4e4f9b, not a live feed. Each record's default geometry is Quattroshapes, sourced from the U.S. Census Bureau — the same provenance cluster as this pack's Census Gazetteer records, not independent corroboration. The New York locality record's five-county hierarchy is retained as context only and is not counted as a boundary assertion. This page presents Who's On First's own published values; it is not the place to compare Who's On First against other sources — that comparison lives on NYC Boundaries.
