NYC OpenStreetMap Relations

Knowledge resource

A governed public view of OpenStreetMap as a boundary-data publisher — the ten exact administrative relation versions used by NYC Boundaries: one county-level and one borough-level relation for each of the five NYC counties. For how these relations compare against DCP, the Census Bureau, NYS Civil Boundaries, and other independently governed sources, see NYC Boundaries.

Dataset

OpenStreetMap has no separate catalog datasets the way a government open-data portal does — each administrative area is its own directly editable relation. This page governs ten specific relation versions, retrieved via the OSM API (version 0.6).

Relations

All ten governed relations, as published by OpenStreetMap. Each county has both a county-level relation (admin_level 6) and a borough-level relation (admin_level 7) — the same real-world extent represented under two administrative framings, not two independent boundaries.

Validation and provenance

Each relation's version number, edit timestamp, administrative tags, and identifiers were retrieved directly from the OpenStreetMap API (version 0.6) and cross-checked against the governed assertion records; this page does not independently verify OSM's underlying geometry. For independent cross-source verification of these relations, see NYC Boundaries.

Scope
OpenStreetMap's own published relation versions, as OpenStreetMap contributors edited them — not an independent recomputation. Confidence is Moderate rather than High because OSM is a crowd-sourced, continuously editable map, not a single authoritative publisher.

Limitations

OpenStreetMap is community-edited and can change at any time; the versions governed here are the exact versions retrieved on 2026-08-08, not a live feed. Each county's two relations (county and borough) represent the same real-world extent under different administrative framings, not two independent boundaries. This page presents OSM's own published values as OSM contributors edited them; it does not independently verify OSM's geometry, and it is not the place to compare OSM against other sources — that comparison lives on NYC Boundaries.
