Validation and provenance

Each representation's shapeID and identity were retrieved directly from the geoBoundaries API and cross-checked against the governed assertion records via exact bounding-box review; this page does not independently verify geoBoundaries' underlying geometry, which is itself a generalized derivative of Census MAF/TIGER data. For independent cross-source verification of these representations, see NYC Boundaries.

Limitations

The five governed representations are the exact versions retrieved at the pinned commit 9469f09, not a live feed. geoBoundaries' own shapeID values identify a geometry within one build and are not stable across releases. The geometry is generalized and shoreline-clipped, sourced from the U.S. Census Bureau — the same provenance cluster as this pack's Census Gazetteer and TIGER records, not independent corroboration. This page presents geoBoundaries' own published values; it is not the place to compare geoBoundaries against other sources — that comparison lives on NYC Boundaries.
