Validation and provenance

Each representation's geometry, version, and source relation were re-queried directly against the pinned release Parquet asset at publication time and cross-checked against the governed assertion records; this page does not independently verify Overture's underlying geometry, which derives from the governed OpenStreetMap relations. For independent cross-source verification of these representations, see NYC Boundaries.

Disclosed correction: at publication time, ten of the eleven representations returned is_territorial=true where this collection's original governed capture had recorded false (only Richmond County's land representation returned false). Geometry, version, and OSM source relation all matched the original capture exactly. A follow-up root-cause investigation — an unchanged release-asset checksum, a reproducible duplicate-free query, and a 99.6% true base rate across the full release — concluded this was an error in the original governed capture, not a live Overture data change. The governed source's prose disposition was corrected accordingly, and the corrected values (shown in the table above) are what this page publishes.

Limitations

The eleven governed representations are the exact versions re-queried against release 2026-07-22.0 at publication time, not a live feed. Each representation derives from an already-governed OpenStreetMap relation — the same provenance cluster, not independent corroboration. No numeric area is published in Overture's own metadata. This page presents Overture's own published values, including the disclosed is_territorial correction described above; it is not the place to compare Overture against other sources — that comparison lives on NYC Boundaries.
